# AI Usage Monitor

macOS menu bar extra that shows Claude, OpenAI (ChatGPT/Codex), Grok, GitHub Copilot, Cursor,
Muse Code (Meta) and OpenCode Go subscription usage limits (session, weekly and monthly windows)
by reusing the credentials the vendors' own CLIs and apps already store on the Mac. Open source,
MIT.

## Stack

- Swift 6 language mode, SwiftUI, minimum macOS 26 (Tahoe), built with Xcode 26.6. Must also run
  on macOS 27.
- Project file is generated by XcodeGen from `project.yml`; run `scripts/bootstrap.sh`.
  Never hand-edit `UsageMonitor.xcodeproj` (it is gitignored).
- Two layers: thin app target in `App/` (scenes and views only) and the local Swift package
  `Packages/UsageMonitorCore` (all logic). See `docs/adr/0001`.
- Zero runtime third-party dependencies. Dev tools only: XcodeGen, SwiftLint.

## Build and test

```sh
scripts/bootstrap.sh                      # xcodegen generate
swift test --package-path Packages/UsageMonitorCore --enable-code-coverage
scripts/coverage-gate.sh                  # fails below 90% line coverage on Core
xcodebuild -project UsageMonitor.xcodeproj -scheme UsageMonitor -destination 'platform=macOS' test
```

## Architecture conventions

- Every provider is a `UsageProvider` in `Sources/UsageMonitorCore/Providers/<Vendor>/` made of
  three parts: a `CredentialSource`, an HTTP client call, and a pure response mapper. Mappers are
  pure functions over `Data` so they are trivially testable with JSON fixtures.
- All external effects go behind protocols with in-memory fakes in the test target:
  `HTTPClient`, `CredentialSource`, `KeychainReader`, `FileSystem`, `SettingsStore`, `Sleeper`.
  Views and view models never touch `URLSession`, `SecItem*`, `FileManager` or `Task.sleep`
  directly.
- `UsageMonitorModel` (`@MainActor @Observable`) is the single source of truth for the UI.
  Views read it from the environment; they never construct providers.
- App target uses default MainActor isolation; Core is nonisolated by default with explicit
  `@MainActor` on UI-facing types.
- Time is injected (`now: () -> Date`, `Sleeper`). No `Date()` or `Timer` in Core outside the
  live factories.

## Credentials and security (non-negotiable)

- The app never persists a vendor token, cookie or refresh token. Credentials are read from the
  vendors' own stores at poll time and kept in memory only. See `docs/adr/0002`.
- Never refresh or rotate a vendor token. On 401, re-read the store once, then fail closed.
- Never log a token, cookie, JWT or response body. Log outcomes, status codes and durations.
  Use `privacy: .private` for anything derived from credentials.
- Never call inference endpoints. Usage requests are read-only: GET, or POST to idempotent usage
  RPCs where the vendor accepts nothing else (Cursor, Muse Code). See `docs/adr/0003`.
- Read-only POST is allowed for idempotent usage RPCs (Cursor, Muse Code); any credential a
  response returns is decoded past and never kept (ADR 0003 amendment).
- Cap response bodies at 1 MB. Validate every decoded field before use.

## Decisions

- Architecture Decision Records live in `docs/adr/`. Read them before changing provider,
  credential, sandbox, testing or observability behaviour; write one for any new pattern,
  integration, data model or significant trade-off.

## Testing

- Swift Testing (`import Testing`) for Core; XCUITest smoke suite in `UITests/`.
- Coverage floor is 90% line coverage on `UsageMonitorCore`, enforced in CI. SwiftUI view
  bodies in `App/` are excluded from the gate (see `docs/adr/0005`).
- Every provider ships fixtures for: happy path, missing optional fields, malformed JSON,
  oversized body, 401, 403, 429 and 5xx. Every credential source ships tests for a missing
  store, an unreadable store and a malformed store.
- Never modify a test to make it pass. Never skip a test without an issue link.

## Style

- 4-space indent, Swift API Design Guidelines naming.
- Prefer `guard` and early return; async/await over completion handlers; typed throws
  (`throws(ProviderError)`) at provider and credential boundaries.
- Comments explain WHY, never WHAT. No docstring boilerplate.
- Commits: imperative mood, under 72 characters, one concern per commit.
